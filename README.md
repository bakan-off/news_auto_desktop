# КМЦБС Новости - Desktop Client

Десктопное приложение для автоматизации сбора, форматирования и отправки новостей от филиалов библиотечной системы. Приложение разработано для замены старой веб-версии на базе Flask, предлагая автономную работу без необходимости оплаты хостинга.

> **Дорабатываете проект (самостоятельно или с ИИ-агентом)?** Прочитайте [DEVELOPMENT.md](DEVELOPMENT.md) — исчерпывающий справочник: архитектура, потоки данных, хранение секретов, релизный процесс, история всех багов проекта и правила, которые нельзя нарушать.

## Особенности
*   **Современный интерфейс:** тёмная (основная) и светлая темы оформления; переключение — в настройках (создано на базе CustomTkinter).
*   **Простой вход:** один экран — почта получателя и пароль, без кодов и писем; на повторных запусках программа открывается сразу.
*   **Без паролей в программе:** секретов в коде нет; пароль выдаёт администратор лично и хранится в Диспетчере учётных данных Windows.
*   **Многопользовательская поддержка:** несколько сотрудников работают с одного ПК — каждый указывает свою почту прямо в форме отправки.
*   **Настоящий автор новости:** почта автора подтверждается кодом из письма (один раз, пока не смените её) — администратор отвечает автору прямо из письма, «левые» адреса не проходят.
*   **Умные хештеги:** Автоматическое формирование списка хештегов, управление тегами в настройках, отзывчивый grid-дизайн.
*   **Миниатюры вложений:** прикреплённые фото показываются превью (с учётом поворота камеры), у каждого файла — имя и размер.
*   **Счётчики и лимиты:** счётчики символов заголовка и описания; предупреждение о большом весе вложений (от 50 МБ) и жёсткий предел (200 МБ) до отправки.
*   **Предпросмотр письма:** как отчёт будет выглядеть у администратора — до отправки, в браузере. Соцсети без галочки показаны красными — сразу видно, куда новость не уйдёт (по умолчанию отмечены только ВК, Одноклассники и Max).
*   **История отправок:** полная карточка каждой новости (описание, теги, ссылки на файлы в облаке), «Просмотр» и «Повторить» — новая публикация на основе старой.
*   **Автосохранение:** незавершённая новость при закрытии окна молча сохраняется в черновики.
*   **Устойчивая отправка:** повторные попытки при сбоях WebDAV/SMTP; при неудаче новость можно сохранить в черновики одним нажатием.
*   **Проверка обновлений:** приложение сверяет версию с GitHub после входа (см. «Релизы» ниже).
*   **Интеграция с WebDAV:** Автоматическое создание папок и загрузка прикрепленных медиафайлов (фото, документы) в облако Mail.ru.
*   **Интеграция с SMTP:** Фоновая генерация HTML-отчетов и отправка их администратору на почту. Оформление текста (переносы строк, стих столбиком) сохраняется в письме.
*   **Drag & Drop:** Поддержка перетаскивания файлов прямо в окно программы.
*   **Локальное хранение:** Все настройки хранятся локально в `config.json`, пароль — в Диспетчере учётных данных Windows.

## Установка и запуск

### Требования
*   Python 3.12 или новее.
*   ОС Windows (для поддержки Drag & Drop).

### Шаги установки

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/bakan-off/news_auto_desktop.git
    cd news_auto_desktop
    ```

2.  Создайте виртуальное окружение и установите зависимости:
    ```bash
    python -m venv venv
    venv\Scripts\activate  # Для Windows
    pip install -r requirements.txt
    ```

3.  Запустите приложение:
    ```bash
    python main.py
    ```
    *(На некоторых системах Windows используйте команду `py main.py`)*

## Первый запуск

При первом запуске появится единственный экран входа: почта получателя новостей (уже заполнена) и **пароль облачного аккаунта** — его выдаёт администратор лично. Не знаете пароль — напишите администратору на `muk_kmcbs_smi@mail.ru`. Программа проверит пароль и запомнит его на этой машине (в Диспетчере учётных данных Windows); на повторных запусках она открывается сразу. В самой программе паролей нет.

В форме отправки укажите свою рабочую почту (автор новости) и подтвердите её: на почту придёт код из 6 цифр, введите его тут же, под полем. Подтверждение нужно один раз — пока не смените почту: именно на неё администратор ответит, если в новости появятся вопросы. Филиал по умолчанию не выбран — выберите свой в списке (или «Не указывать»); программа запомнит ваш выбор.

## Техническая настройка (для Администратора)

Паролей в коде программы нет — при первой настройке их вводит сотрудник. Изменить серверы или адреса можно после входа:
1. Запустите приложение.
2. Перейдите в раздел **"Настройки"**.
3. Поставьте галочку **"Режим администратора (Тех. данные)"**.
4. В появившемся блоке укажите логины, пароль облачного аккаунта и адреса для WebDAV и SMTP.
5. Нажмите "Сохранить настройки": пароль уйдёт в Диспетчер учётных данных Windows, остальное — в `config.json`.

> **Внимание:** Файл `config.json` добавлен в `.gitignore`. Никогда не публикуйте его в репозиторий.

## Архитектура
*   `main.py` — Точка входа и UI (Tkinter/CustomTkinter).
*   `core.py` — Прикладная логика без UI (конфиг, валидация, сборка письма) — покрывается автотестами.
*   `theme.py` — Палитры тёмной/светлой темы; все цвета UI берутся только отсюда.
*   `tests/` — Автотесты (pytest).
*   `config.json` — (генерируется автоматически) Хранилище сессий, хештегов и настроек подключения. Создаётся рядом с `main.py` (или рядом с `.exe` в собранном приложении), а не в текущей папке запуска; пароль живёт в Диспетчере учётных данных.
*   `app.log` — (генерируется автоматически) Журнал работы приложения с ротацией; полезен при диагностике проблем в филиалах.
*   `requirements.txt` — Зависимости приложения, `requirements-dev.txt` — зависимости для разработки (pytest, ruff).

## Сборка .exe

Дистрибутив собирается одной командой из корня проекта (venv должен быть активирован):

```bash
pwsh -File build.ps1
```

Скрипт собирает onedir-exe (PyInstaller, с иконкой и файлами customtkinter), сохраняет ваш личный `config.json`/`app.log` в локальной папке сборки (чтобы после обновления не входить заново) и пакует в `dist\КМЦБС-Новости.zip` **чистый** архив — без `config.json` и `app.log`, с пустой конфигурацией для новой машины.

Эквивалентная команда PyInstaller вручную:

```bash
python -m PyInstaller --onedir --noconsole --clean --collect-data customtkinter --icon app.ico --add-data "app.ico;." --name "КМЦБС-Новости" main.py
```

Для рассылки в филиалы используйте zip; приложение создаёт `config.json` и `app.log` рядом с exe при первом запуске. Иконка окна и exe — `app.ico` из корня проекта.

> Сборка `--onefile` (один exe-файл) возможна, но не рекомендуется: медленный старт и частые срабатывания антивирусов из-за распаковки DLL во временную папку при каждом запуске.

## Хранение паролей

Единый пароль облачного аккаунта (облако и почта — один аккаунт) хранится в **Диспетчере учётных данных Windows** (записи `КМЦБС_Новости/...`) под учётной записью текущего пользователя. В коде программы и в собранном exe паролей нет: сотрудник вводит пароль один раз на экране входа, получить его можно только у администратора лично (подсказка с адресом администратора — прямо на экране входа). Если диспетчер недоступен — программа работает через `config.json` (тогда файл содержит пароль и публиковать его нельзя ни при каких условиях).

## Релизы и проверка обновлений

Версия приложения — `APP_VERSION` в `core.py`. Приложение проверяет теги `vX.Y.Z` в веб-ленте тегов этого же (публичного) репозитория — после входа автоматически и кнопкой в настройках — и предлагает открыть страницу загрузки, если найдена новая версия. Лента тегов не расходует лимиты GitHub API, поэтому проверка работает даже за офисным NAT с общим IP.

Репозиторий один и публичный: исходный код и релизы (zip-архивы сборок) живут вместе, секретов в коде нет.

Чтобы выпустить версию:

1. Поднимите `APP_VERSION` в `core.py`, сделайте коммит, соберите сборку: `pwsh -File build.ps1`.
2. Пометьте и отправьте исходники: `git tag vX.Y.Z && git push origin main vX.Y.Z`.
3. Опубликуйте релиз одной командой: `pwsh -File publish_dist.ps1` — она создаст Release с описанием и загрузит чистый `dist\КМЦБС-Новости.zip` как `KMCBS-News-<версия>.zip`.
